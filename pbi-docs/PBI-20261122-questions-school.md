# Questions for the school: Pasok classroom attendance helper   (answer by: before any real students are added)

Pasok is a small helper website for one advisory class. The class secretary records who is absent, the adviser confirms it, and parents check their own child's attendance through a private link. It is **not** the official attendance record. Before we use it with real students, we need the school's guidance on the points below.

**Quick path:** reply "all ★" to accept every recommendation.

## Privacy and approval

### Q1. May the adviser use this tool with real student names?   (blocks real use)
Right now the tool runs only with made-up students. Real use would store each student's name, daily attendance, absence reasons and short notes. Parents see only their own child's record. There are no ads, and nothing is shared outside the class.
